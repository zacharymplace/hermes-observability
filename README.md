# Hermes Observability

Reusable observability standards and helpers for Hermes-aligned repos.

## Current Standard

Events:

- command-result
- review-summary
- release-lineage
- final-disposition

Scores:

- readiness
- risk
- confidence

## Local Usage

```bash
source ~/.config/hermes/langfuse.env
npm run trace:smoke
```
